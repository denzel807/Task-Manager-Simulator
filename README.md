# Process Scheduler

Графическое приложение на C# для моделирования работы диспетчера операционной системы и планирования выполнения процессов.

Программа реализует алгоритм планирования **Round Robin**, при котором каждой задаче выделяется определенный квант процессорного времени. Если задача не успевает завершиться за выделенный квант, она возвращается в конец очереди и продолжает выполнение позже.

## Основные возможности

- добавление пользовательских задач;
- указание имени и времени выполнения задачи;
- настройка кванта процессорного времени;
- формирование очереди готовых процессов;
- автоматическое выполнение задач;
- переключение между задачами после окончания кванта;
- отображение текущего состояния выполнения;
- визуальное отображение прогресса каждой задачи;
- отображение оставшегося времени выполнения;
- расчет процента выполнения;
- формирование списка завершенных задач;
- отображение времени завершения задач;
- возможность приостановить автоматическую симуляцию;
- полный сброс симуляции и повторный запуск.

## Алгоритм планирования

В проекте используется алгоритм **Round Robin**.

Все новые задачи помещаются в очередь готовых процессов. Планировщик выбирает первую задачу из очереди и переводит ее в состояние выполнения.

За каждый шаг:

1. оставшееся время задачи уменьшается;
2. увеличивается использованный квант времени;
3. если задача завершилась, она получает состояние `Completed`;
4. если квант закончился раньше завершения задачи, процесс возвращается в конец очереди;
5. планировщик выбирает следующую задачу.

Такой подход позволяет распределять процессорное время между несколькими процессами по очереди.

## Состояния задач

Для процессов предусмотрены следующие состояния:

- `Waiting` — ожидание;
- `Ready` — готова к выполнению;
- `Running` — выполняется;
- `Completed` — завершена.

## Интерфейс

Приложение имеет графический интерфейс Windows Forms.

В окне программы можно:

- создавать новые задачи;
- задавать время их выполнения;
- изменять квант времени;
- наблюдать список активных процессов;
- следить за процентом выполнения;
- видеть текущую выполняемую задачу;
- просматривать отчет по завершенным процессам;
- запускать и останавливать автоматическую симуляцию;
- сбрасывать состояние планировщика.

## Структура проекта

### `Task`

Представляет отдельный процесс и хранит:

- идентификатор;
- название;
- исходное время выполнения;
- оставшееся время;
- текущее состояние;
- использованный квант;
- цвет для визуализации;
- время завершения.

### `MainForm`

Основной класс приложения.

Отвечает за:

- графический интерфейс;
- создание процессов;
- управление очередью;
- выполнение алгоритма Round Robin;
- обработку таймера;
- отображение прогресса;
- формирование отчетов;
- управление симуляцией.

### `Program`

Точка входа в приложение, запускающая главную форму.
